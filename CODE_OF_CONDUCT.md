# Code of conduct

Project participation should remain professional, constructive, and focused on
the work. Harassment, discrimination, threats, deliberate disclosure of private
information, and sustained personal attacks are not acceptable in project
spaces.

Contributors should critique ideas and evidence rather than people, respect
different levels of experience, disclose relevant conflicts, and avoid
overstating scientific results. Maintainers may edit, hide, reject, or remove
content and participation that does not meet these expectations.

For conduct concerns, contact the repository maintainer privately through
GitHub when possible. Use GitHub's block and abuse-reporting tools for urgent
platform safety issues. Do not use public issues to disclose another person's
private information. Security reports should follow [SECURITY.md](SECURITY.md).
